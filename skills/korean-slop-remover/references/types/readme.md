# README

실제 교정 사례를 일부 반영했지만 아직 초안이다. 쓰다가 어색한 결과가 나오면 이 파일부터 고친다.

## 독자

저장소에 처음 온 사람이다. 위에서부터 훑으면서 이게 무엇인지, 나한테 필요한지, 어떻게 쓰는지를 확인하고 필요한 곳에서 멈춘다.

## 구성

1. 첫 문단에 이게 무엇인지, 누가 왜 만들었는지 쓴다. 만든 사람의 목소리로 쓴다.
2. 설치
3. 사용법
4. 필요하면 설정, 동작 방식, 기여나 문의

## 말투

담백한 ~합니다체로 쓴다. "~해요" 같은 대화체는 쓰지 않는다.

## 제목, 굵은 글씨, 그림

- 제목은 "설치", "사용법"처럼 관례적인 명사로 단다. "어떻게 쓰나요?" 같은 질문형은 쓰지 않는다.
- 굵은 글씨는 거의 쓰지 않는다. 설치 전에 꼭 알아야 할 조건 하나 정도다.
- 그림은 실제 화면 하나나 구조도 하나면 충분하다.
- 명령어는 그대로 복사해 쓸 수 있게 코드 블록으로 쓴다.

## 자주 나오는 슬롭

- 첫 줄에 굵은 슬로건이 있다.
- 기능을 "강력한", "손쉬운" 같은 형용사를 붙인 불릿으로 나열한다.
- 배지와 이모지로 위쪽을 채운다.
- 써 보면 저절로 아는 동작을 설명한다.

## 예시

> # minutes-cli
>
> 회의 녹음 파일을 넣으면 회의록 초안을 만들어 주는 명령줄 도구입니다. 매주 회의록을 손으로 정리하는 데 시간이 많이 들어서 만들었습니다.
>
> ## 설치
>
> ```
> pip install minutes-cli
> ```
>
> ## 사용법
>
> ```
> minutes-cli 회의.m4a
> ```
>
> 같은 폴더에 `회의.md`가 생깁니다. 회의록 형식을 바꾸고 싶으시면 `--template`으로 직접 만든 템플릿 파일을 넘기시면 됩니다.
